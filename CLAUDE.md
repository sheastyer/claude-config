# Global conventions (all projects)

This is my user-level memory, loaded for every project. Keep it to conventions
that are true across all my work; anything project-specific belongs in that
repo's own `CLAUDE.md`.

## Working style
- Report the concrete outcome, including the PR URL, in your final message.
- When the same manual task or question keeps recurring, propose automating
  it (a hook, a skill, or a scheduled agent) instead of doing it by hand
  again.
